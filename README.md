# CrsterUtility

A powerful, modern utility application built for the Windows ecosystem using **WinUI 3** and **.NET 10.0**.

## 🚀 Overview

CrsterUtility is designed to provide a collection of helpful tools for power users and developers, leveraging cutting-edge Windows technologies to deliver a fast, fluid, and native user experience.

## 🛠 Tech Stack

*   **Framework:** .NET 10.0 (WinUI 3)
*   **Platform Support:** x86, x64, ARM64
*   **Key Dependencies:**
    *   **UI/Graphics:** `Microsoft.WindowsAppSDK`, `Microsoft.Graphics.Win2D`
    *   **Data:** `LiteDB`
    *   **Media:** `NAudio`
    *   **Utilities:** `Markdig` (Markdown processing), `Cronos` (Cron scheduling), `Vortice.Direct3D11` (DirectX interop)

## 📦 Packaging

This project is configured for **MSIX** packaging, ensuring secure installation, clean updates, and seamless integration with the Windows environment.
